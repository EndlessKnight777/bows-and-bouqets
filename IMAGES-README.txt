HOW TO ADD YOUR PHOTOS
=======================

The site is already wired up to show real photos the moment you add them.
Nothing else needs to change in the code, just save your photo with the
exact file name below into the matching folder, and it will replace the
pink placeholder icon automatically.

If a photo is missing, the placeholder icon just stays there quietly,
nothing breaks.

Create a folder called "images" in the same place as index.html, then
inside it, these folders and file names:


1. HOMEPAGE PRODUCT PHOTOS
   Folder: images/products/
   Files:
     deluxe-rose-arrangement.jpg
     blush-elegance-box.jpg
     seasonal-display.jpg
     gourmet-snack-boxes.jpg
     laser-cut-personalization.jpg
     bespoke-bouquets.jpg


2. OUR STORY PAGE PHOTO
   Folder: images/story/
   File:
     shop.jpg
   (used on both the homepage and the Our Story page)


3. GALLERY PAGE
   Folder: images/gallery/
   Each category gets its own folder, with a cover photo plus up to
   8 photos shown when someone taps that category:

     images/gallery/balloons/cover.jpg
     images/gallery/balloons/1.jpg  (through 8.jpg)

     images/gallery/blooms/cover.jpg
     images/gallery/blooms/1.jpg  (through 8.jpg)

     images/gallery/chocolate-packages/cover.jpg
     images/gallery/chocolate-packages/1.jpg  (through 8.jpg)

     images/gallery/misc/cover.jpg
     images/gallery/misc/1.jpg  (through 8.jpg)

     images/gallery/snacks/cover.jpg
     images/gallery/snacks/1.jpg  (through 8.jpg)

   You do not need all 8 for every category to start. If you only have
   3 photos of balloons right now, just add 1.jpg, 2.jpg and 3.jpg.
   The empty slots quietly stay as placeholders until you add more.


4. SOCIAL SHARE PHOTO
   Folder: images/
   File:
     og-cover.jpg
   This is the photo that shows up when someone shares your website
   link on Facebook, Instagram or WhatsApp. A nice wide photo of a
   bouquet or the shop front works well. Recommended size: roughly
   1200 x 630px.


A FEW TIPS
   - Square or close-to-square photos look best (roughly 1000 x 1000px
     is plenty, no need for huge camera-original files).
   - JPG works fine for photos, keep each file under about 500KB if
     you can, so pages load quickly on phones.
   - File names must match exactly, all lowercase, with the dashes
     shown above.
